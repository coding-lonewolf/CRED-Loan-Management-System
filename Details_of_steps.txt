

# Chunking Strategy
One important detail: all-MiniLM-L6-v2 has a maximum input sequence length of 256 tokens. Longer inputs can be truncated, so the script uses relatively small character-based chunks as starting values. Character count is not equivalent to token count; validate actual token lengths before indexing.
